# 产品范围

## 产品目标

FloatingPod 是面向 Minecraft 1.12.2 Cleanroom 环境的浮游辅助单元 Mod。它为玩家提供可部署、跟随、召回、升级和脚本化的辅助机；辅助机的实际状态和行为由服务端裁决，客户端只呈现配置界面、Gecko 模型与动画，并发送用户输入。

项目保持独立，只复用已经验证的 Cleanroom、Gradle、CraftTweaker 和渲染依赖配置。Catroom、Bukkit 及其兼容层不属于核心范围。

## 当前交付边界

首个纵向原型只实现下列能力，并以“跟随策略数据盘”贯通物品安装、配置界面、服务端校验、持久化和实体行为：

1. 辅助机的包装、拆包、激活、绑定、释放与召回。
2. 玩家辅助机终端、配置 GUI 及 Baubles 装备支持。
3. 通用模块槽位中的行为模块安装和拆卸。
4. 以服务端为准的跟随行为，包括同维度传送和传送门场景。
5. 全服活动辅助机上限的检查与展示。
6. 管理员可用的辅助机数据迁移包导入和导出。

战斗、采集和物品存储是后续的功能性行为模块。它们会沿用模块、权限、服务端权威与持久化合同，但本规划不预先承诺目标选择、采集规则、库存容量、掉落归属或平衡数值。

## 玩家权益与活动限制

玩家的“可注册数量”和“可同时激活数量”是两套独立的永久权益，初始值均为 1。两类特定消耗型升级分别提高对应权益。

- 降低服务端配置的上限时，不删除超额已注册辅助机，也不自动收回超额活动实体。
- 管理员可使用指令强制执行超额辅助机的收回。
- 全服活动辅助机硬上限由配置决定，默认值为 256；达到上限时服务端拒绝新的释放请求。
- 辅助机终端显示全服活动计数，例如 `16 / 256`，以便玩家在释放前了解容量。

## 模块与配置

行为模块是保留自身配置的真实 `ItemStack`。模块从辅助机配置 GUI 安装或拆卸；拆卸后原样返还，模块自身配置不丢失。

模块使用通用槽位而非固定类别栏位。每个模块声明自身的类别、槽位成本、冲突项和依赖项，由服务端验证最终组合。这使服务端配置与 ZenScript 能调整组合规则，而不固化 GUI 中的类别数量。

首个模块为“跟随策略数据盘”，其配置项为跟随距离、相对方位和移动模式。它不引入战斗、采集或物品库存的实现复杂度。

辅助机同时具备电量、耐久和基础护盾状态。护盾状态由 FloatingPod 维护，并与可用的 Draconic Evolution API 联动；它不把辅助机伪装为玩家的 Draconic Evolution 护盾。

## 生命周期与交互

辅助机的完整产品流程见 [05-lifecycle-and-interactions.md](05-lifecycle-and-interactions.md)。其中包括包装拆包、`UNBOUND` 预留、激活密钥、终端召唤、配置 GUI、收回动画、传送、死亡、离线和转让。

## 脚本、权限与管理

- 服务端 config 提供玩家自定义行为总开关。关闭时，玩家只能调整管理员预制脚本明确声明的配置项，不能提交或生成玩家脚本；开启时，提交与生成仍需对应权限组授权。
- ZenScript 由服务器管理员加载。获授权玩家只能提交脚本，管理员通过辅助机终端审批后，玩家才可使用空数据盘生成已批准版本。
- 审批绑定精确内容哈希和不可变版本。修改脚本必须重新审批；撤销后，现有数据盘仍保留物品形式，但显示“已撤销”且不得继续执行。
- FloatingPod 只向玩家脚本开放显式的辅助机 API。文件、网络、线程、反射和通用 CraftTweaker 全局能力不在脚本边界内。
- LuckPerms 存在时是权限事实来源，内置权限组作为无 LuckPerms 环境的后端并保存审批流程状态；任何明确拒绝优先于允许。
- 管理员可在服务器运行期间导出或导入辅助机迁移包。迁移包不包含当前实体、Forge ticket、节点会话或数据库凭据；导入后保持收回状态。

## 质量边界

- 服务端是所有权、绑定、模块、物品、脚本版本、行为结果和活动数量的唯一裁决者；客户端伪造请求不能产生未授权结果。
- Gecko 模型、动画、粒子与音效仅表达已获服务端确认的状态，不能参与业务裁决。
- 已确认生命周期在服务端重启、传送、死亡、离线和转让后保持一致的所属关系与持久状态。
- 关键操作失败必须向玩家给出明确结果，并由服务端记录可定位日志；不能部分完成后伪装成功。

## 非目标

- 不支持传统 Forge 1.12.2 Java 8 环境，运行目标仅为 Cleanroom 与满足 Scalar `>=3.8.4` 最低前置的版本。第一版选用官方分发 artifact `3.8.4-1`，其 Scalar `mcmod.info` / FML runtime mod version 为 `3.8.4`；客户端和专用服务端加载仍待验证。
- 不支持客户端本地脚本作为权威行为来源。
- 不承诺与所有路径查找、领地、权限或物品管道 Mod 的兼容。
- 不将尚未实现的战斗、采集、存储细节、性能指标或平衡数值视为既定承诺。
